# API Lifecycle — nodary dashboard

Versioned contracts: `src/nodary/scoring/registry.py:ENGINE_VERSION` (currently `1.1.0`), `src/nodary/feature_extraction/profiles.py:PROFILE_VERSION` (1), `src/nodary/scoring/tiers.py:TIER_LABELS`.

## Wire contract source of truth

`src/nodary/ui/schemas.py` TypedDicts → `docs/specs/openapi.json` (generated by `get_openapi_spec()`) → `src/nodary/ui/server.py` handlers. CI fails if `openapi.json` drifts from `schemas.py` (see `.github/workflows/ci.yml` openapi-drift job).

## Deprecation policy

- **Threshold/weight changes:** Changing any `FEATURES[feature].weight` or `TIER` rule requires minor version bump (`0.3.x → 0.4.0`) and entry in `CHANGELOG.md` + `docs/API-LIFECYCLE.md` changelog below.
- **Wire shape changes:** Renaming/removing a field in `ScoredMessage`, `SenderDetailResponse`, or error envelope requires deprecation period: add `X-Deprecated: <field> will be removed in 0.x+2` header for one minor, then remove. Document in `openapi.json` `deprecated: true`.
- **Pagination envelope** (`{data, pagination}`) is stable since `0.3.1`. Bare-array responses are removed; clients must unwrap `payload.data ?? payload`.
- **Naming:** Wire is `snake_case` (`anomaly_score`) for Python parity (P2-1 deviation from skill camelCase). Documented in `openapi.json` description for `/api/accounts`.
